# one.

# WHY THIS EXISTS SEPARATELY FROM THE PUBLISHED .sha256. The control-plane
# release publishes a .sha256 beside every tarball, and the fetch checks
# against it too. But that file proves only that the tarball matches what the

# that can replace one can replace the other. This pin proves it is still the
# tarball this repository was built and tested against. A build gets the agent
# only when BOTH agree.
#
# The binary this names is baked into the firewall image, runs as root on the
# node that terminates the WAN, and holds the bus join credential. It is the
# one file in this build that is not produced by OpenWrt's ImageBuilder and not
# covered by a package feed signature.
