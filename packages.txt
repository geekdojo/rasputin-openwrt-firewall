# --- GPU/video kmods we don't need on a firewall ---
# OpenWrt 24.10's x86 default profile pulls in the entire DRM stack
# (kmod-drm-i915, kmod-drm, kmod-drm-display-helper, kmod-drm-ttm, ...
# 11 packages totalling ~3 MB) transitively via kmod-acpi-video. None
# of it serves any purpose on Node N — efifb (set up by UEFI firmware)
# provides the framebuffer console fine, and we have no display
# attached in production anyway. kmod-drm-i915 also tries to fetch
# non-free GuC firmware that isn't in the OpenWrt feed (on N100 /
# Alder Lake-N the blob is i915/tgl_guc_70.bin), producing a
# [drm] *ERROR* cascade on every boot. Dropping the package removes
# both the wasted RAM and the error noise.
#
# IMPORTANT learning from the CWWK x86-p5-n100 bring-up 2026-06-07:
# putting `i915.enable_guc=0` on the kernel cmdline does NOT silence
# the GuC error — OpenWrt's busybox kmodloader/modprobe doesn't
# propagate /proc/cmdline params to loadable modules (verified
# empirically: /proc/cmdline showed our args, but
# /sys/module/i915/parameters/enable_guc still read -1 after boot).
# The only reliable knob for loadable modules in OpenWrt is dropping
# them at the package level. Hence -kmod-drm-i915 here, and not in
# patch-image-cmdline.sh (which we keep as belt-and-suspenders for
# built-in drivers, even though it's a no-op for i915 today).
-kmod-drm-i915
-kmod-acpi-video

# --- IDS (tap mode via UCI method=pcap, action=alert) ---
# Locked 2026-06-08: ship snort3 from the OpenWrt 25.12 feed (option (a)
# of the original three-way choice). The Suricata-removed-from-feeds
# blocker that drove the v0 deferral was 24.10-specific; 25.12 has
# snort3-3.10.0.0-r1 and ET Open ships snort3-native rules. Tap mode
# (DAQ=pcap on the WAN interface) is a first-class UCI option in
# /etc/config/snort — no kernel NFQUEUE, no fast-path disruption.
# `action=alert` is the safety belt: even if a rule says "drop", snort
# only logs. The N100 still cannot do inline IPS at line rate, and we
# remain honest about that in firewall-image.md §2.
snort3
